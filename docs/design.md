# Roots visual direction

Seed: 5521554613388362993. Five independent rolls were recorded before frontend code.

| Axis | Result | Purpose |
| --- | --- | --- |
| Palette balance | Ink dominant | Gives evidence the gravity of a public record |
| Layout | Editorial columns | Keeps source material and interpretation in view together |
| Type | Grotesk and slab serif | Space Grotesk handles controls, Roboto Slab carries the editorial voice |
| Motion | State changes only | Motion communicates selection, progress and disclosure |
| Structural device | Pairwise relation lattice | Makes the independence rule visible and inspectable |

Tokens: ink #000000, paper #FFFFFF, decision #313567. Supporting neutrals are derived from these colors. No generic feature grid, tracked uppercase labels, numbered decorations, ambient motion or floating cards. The lattice is the one expressive element. All controls retain visible focus; reduced motion disables transitions.

The main workspace uses a narrow navigation column, a wide evidence column and a contextual inspection column. Small screens collapse inspection below evidence and retain accessible navigation.
